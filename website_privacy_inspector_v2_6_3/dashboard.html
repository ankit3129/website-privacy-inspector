Chrome's cookie API can expose cookies beyond the current page URL when host permissions permit. Cookie deletion cannot always be undone.

Global defaults

Site privacy profiles

Global rules

Rules are stored locally. Notifications and pop-ups use Chrome content settings. Tracker blocking is managed separately. Third-party cookie blocking is not implemented as a global rule here because Chrome's cookie content setting cannot reliably target only third-party cookies.

Tracker blocking

Blocks matching request domains with Chrome's declarativeNetRequest API.

Allowlist

Security analysis

Checks the active tab URL and, where accessible, response headers. This is a lightweight signal report, not a malware scan or full audit.

Header checks only use responses captured while you browse. If no suitable response was captured, the result is unverified—not proof of a vulnerability.

Backup & restore

Export settings, allow/block lists, trusted sites, profiles, and privacy history to a JSON file. Backups can contain domains and browsing-related notes; keep the file private.

Restore replaces the extension's saved configuration. It does not restore deleted cookies or undo Chrome settings changes.
